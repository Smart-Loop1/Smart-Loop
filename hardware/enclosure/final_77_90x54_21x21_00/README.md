# Smart Loop enclosure — final measured revision

This revision preserves the rounded shape, recessed lid, four corner fasteners,
and engraved water-drop styling of the original Smart Loop enclosure.

## Measured electronics envelope

- Length: `77.90 mm`
- Width: `54.21 mm`
- Height: `21.00 mm`

## Finished enclosure

- External size: `97.90 x 74.21 x 29.90 mm`
- Internal usable size: `92.90 x 69.21 x 25.00 mm`
- Wall: `2.50 mm`
- Floor: `2.40 mm`
- Lid: `2.50 mm`
- XY clearance around electronics: `7.50 mm` per side
- Clearance above electronics: `4.00 mm`

## Openings

- Water-flow sensor cable: `8.50 mm` round opening, centered on the side wall
- Two USB-C openings: 13.50 x 7.00 mm each, vertically stacked on the rear wall
- No external switch or LED openings; the enclosure is opened for operation

## Fasteners

- Four aligned corner fastening points
- Four printable hand-turn thumb screws are supplied in one separate file
- One single-screw file is also supplied for replacement prints
- Standard M3 hardware can be used as a stronger alternative

## Print files

- `smart_loop_base.stl`
- `smart_loop_lid.stl`
- `smart_loop_screws_4x.stl`
- `smart_loop_screw_single.stl`
- Matching `.step` files are included
- `smart_loop_enclosure_assembly.step` is an assembled reference model
- `smart_loop_lid_profile.svg` is a dimensioned 1:1 lid outline

## Suggested print settings

- Material: PETG preferred; PLA is acceptable for a display prototype
- Layer height: `0.20 mm`
- Walls/perimeters: `4`
- Infill: `25%`
- Print the base upright with its floor on the bed
- Print the lid exterior face on the bed
- Print thumb screws upright with their flat wing heads on the bed
- Use a brim for the screws if bed adhesion is weak

Print one screw first and test it in one boss before printing all four. FDM
tolerances vary; if it is too tight, lightly clean the pilot hole with a 2.8–3.0
mm drill bit by hand.
